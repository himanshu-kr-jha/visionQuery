# Confident linking continuously, Following on demand, investigator Assertions are final

A background linker continuously infers only high-confidence Links, so Visits are conservative and fragmented rather than wrongly merged.
When an Operator follows an Anchor, a query-time search extends outward from its Visit and proposes the Links the linker skipped.
Confirmations and Rejections by investigators are Assertions the Deployment never overrides; only a recorded Withdrawal undoes them, and Contradictions are surfaced, never resolved automatically.

## Considered Options

Continuous-only linking makes accuracy hinge on one threshold.
Query-only linking leaves the Deployment knowing nothing until asked and rules out counting questions.
Treating Operator input as one more weighted signal lets a model overrule a person, which destroys trust.
